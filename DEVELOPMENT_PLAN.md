## 📊 Анализ проекта

**Trello Local** — это локальный менеджер задач с архитектурой MVC на Rust (Axum + SQLite) + Vanilla JS frontend.

### Текущий статус

| Компонент | Статус | Примечание |
|-----------|--------|------------|
| Backend (Rust) | ✅ Готово | Axum, SQLx, JWT, bcrypt |
| Frontend (JS) | ✅ Готово | Vanilla JS, Bootstrap-стили |
| База данных | ✅ Готово | SQLite с миграциями |
| Docker | ✅ Готово | docker-compose, healthcheck |
| Безопасность | ✅ 9.5/10 | Пройден аудит 27.02.2026 |

### Реализованный функционал

- ✅ Аутентификация (JWT + сессии, rate limiting, валидация паролей)
- ✅ CRUD досок, списков, карточек, комментариев, вложений
- ✅ Чек-листы, метки, исполнители
- ✅ Календарь, поиск, экспорт (JSON/CSV)
- ✅ Управление участниками и приглашения
- ✅ История активности

## 🚀 Быстрый старт для разработки

### 1. Клонирование и запуск

```bash
# Клонирование репозитория
git clone https://github.com/alexandervashurin/trello-local.git
cd trello-local

# Запуск через Docker
docker-compose up -d

# Просмотр логов
docker-compose logs -f
```

### 2. Разработка backend

```bash
cd backend

# Сборка
cargo build --release

# Запуск
cargo run

# Тесты
cargo test

# Проверка кода
cargo clippy --all-targets
cargo audit
```

### 3. Frontend

```bash
# Frontend обслуживается статически из папки frontend/
# Откройте в браузере: http://localhost:8080
```

### 4. Переменные окружения

```bash
# .env файл (для разработки)
JWT_SECRET=your-secret-key-here
DATABASE_PATH=./data/trello.db
RUST_LOG=info
FRONTEND_DIR=./frontend
```

## 🧪 Тестирование

### Запуск тестов

```bash
cd backend
cargo test
```

### Интеграционные тесты (8 шт.)

- `test_create_board` — создание доски
- `test_get_boards` — получение списка досок
- `test_create_list` — создание списка
- `test_create_card` — создание карточки
- `test_auth_register` — регистрация пользователя
- `test_auth_login` — вход пользователя
- `test_search_boards` — поиск досок
- `test_comments` — комментарии к карточкам

### Проверка безопасности

```bash
# Аудит уязвимостей
cargo audit

# Статический анализ
cargo clippy --all-targets -- -D warnings

# Проверка форматирования
cargo fmt --check
```
